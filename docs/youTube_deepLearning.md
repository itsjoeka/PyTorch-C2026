## Introduction: Machine Learning Basics
Here, features are manually engineered by hand using certain techniques

### Types
- **Supervised Learning:** parameters of the model is learnt by using data that has label pairs
- **Unsupervised Learning:** parameters of the model are learned by using data without labels
- **Self-supervised Learning:** learn model parameters using dataset of data-data pairs (augmented form of the same dataset)

### Classification/Regression
In Classification, the goal is to predict, using a function f, with an input X, a discrete class label whereas in Regression, you predict a continuous class label
