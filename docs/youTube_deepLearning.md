### Types
- **Supervised Learning:** parameters of the model is learnt by using data that has label pairs
- **Unsupervised Learning:** parameters of the model are learned by using data without labels
- **Self-supervised Learning:** learn model parameters using dataset of data-data pairs (augmented form of the same dataset)
